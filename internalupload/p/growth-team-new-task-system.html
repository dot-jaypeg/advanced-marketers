How We Run Client Work

Read this once. It takes 5 minutes and it covers everything you do in ClickUp from here on.

The whole system in three rules

RULE 1
Group the work
Big thing on top. The steps to do it go underneath as subtasks. Never a flat pile of tasks.
RULE 2
Date it and own it
Every task has one owner and one due date. No owner means nobody is doing it.
RULE 3
Say who to tell
Set Notify When Done. ClickUp tags that manager the second you finish. You never chase.
1

Group the work

One parent task per big thing. The steps go inside it as subtasks.

How to make a subtask: open the parent task → + Add subtask at the bottom. Do not create it as a normal task and try to drag it in. It will not nest.
2

Give it an owner and a due date

Both. Every time. A task with no due date is invisible — nothing chases it and nobody sees it slipping.

Fastest way: do it straight from the list columns. You do not need to open the task.

3

Set “Notify When Done”

This is the one new thing. It replaces you Slacking a manager to say something is finished.

Set it from the list view column — that column is always on screen. Click the cell, pick the route, done.

The six routes. Pick the one that matches the type of work, not the person doing it.

What happens automatically:
• You mark the task COMPLETE → that manager gets tagged in a comment on the task.
• The task hits its due date and is not done → that same manager gets tagged.
No watchers. No Slack message. No "hey did you see this."
If you open a task and can't find the field: ClickUp hides empty custom fields behind a Fields section on the task detail page. Click it to expand — or just set it from the list column instead, which is why we put the column there.
4

It shows up on the client Overview

Every client folder has an Overview tab. The Work card lists the parent tasks with the arrows; Where Things Stand shows the progress bar. That's the client at a glance.

New client → new folder

Cloning a client in 6 clicks

When a new client signs, you do not build anything from scratch. You clone the template. It brings the folder, the Delivery list, the Overview cards, 14 parent tasks with all their subtasks, and the Notify When Done routes already filled in on every task.

  1. In ClickUp, click the space name 🚀 AM Delivery 2.0 at the top, then the … next to it.
  2. Choose Templates → Apply a template.
  3. Search NEW CLIENT and pick NEW CLIENT - Full Setup. Click Use Template.
  4. Type the client's name in the Folder name box. Leave everything else alone (Import everything and Import as is are already correct). Click Use Template.
  5. Open the new folder. Rename the list inside it from Delivery — [Client Name] to Delivery — <Client>.
  6. Delete the parent tasks for anything this client did not buy. Then set Assignee and Due date on everything that's left.

Step 1–2: space menu → Templates → Apply a template.

Step 4: the only thing you change is the Folder name.

What you get. Notice the Notify When Done column is already filled in on all 14 tasks — you don't set those, you only fill in Assignee and Due date.

Two things to fix right after cloning:
1. Every task lands assigned to you (whoever clicked the button). Reassign them to the real owners.
2. Rename the list — it comes over as Delivery — [Client Name].
Only clone from "NEW CLIENT - Full Setup". There are older templates in the list (AM Master Client Template, AM-New Client Template, KM-NEW CLIENT 2.0). Do not use those — they don't have the notify routes.

Do this now — 20 minutes per account

  • Open your client's folder → Delivery list.
  • Anything that's a step inside a bigger job: move it under a parent as a subtask.
  • Give every parent task one owner and one due date.
  • Set Notify When Done on every task using the list column.
  • Open the Overview tab and confirm it looks right.
  • Delete the parents for services this client didn't buy.

Don't do these

  • Don't leave a task with no due date. It disappears.
  • Don't assign three people to one task. One owner.
  • Don't add watchers to get someone notified — that's what Notify When Done is for.
  • Don't build a new client folder by hand. Clone the template.
  • Don't rename or edit the CLIENT TEMPLATE folder. Changes to it go through Requests & Improvements.
